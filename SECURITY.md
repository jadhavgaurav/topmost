# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Topmost, please report it responsibly:

1. **Do not** file a public GitHub issue.
2. Email the maintainer directly at: `gaurav.vjadhav01@gmail.com`.
3. Provide details including:
   - macOS version and architecture.
   - Steps to reproduce the issue.
   - Potential impact of the vulnerability.

We take security issues seriously and will respond promptly to investigate and release patches.
