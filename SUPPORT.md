# Getting help

- **Something is not working:** start with [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md). Most problems are a missing or stale Accessibility or Screen Recording permission.
- **You found a bug:** open a [bug report](https://github.com/jadhavgaurav/topmost/issues/new?template=bug_report.yml).
- **You have an idea:** open a [feature request](https://github.com/jadhavgaurav/topmost/issues/new?template=feature_request.yml).
- **You found a security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).
- **You want to contribute:** read [CONTRIBUTING.md](CONTRIBUTING.md).
